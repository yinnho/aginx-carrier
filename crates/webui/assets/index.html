本机网关

本机列表来自本机 aginx 网关（agent:// listAgents）；远程网关走同一协议（算力在他家，会话在对方侧，凭 sessionId 续接）。聊天经网关路由到对应 CLI；移除会一并清掉该联系人的会话记录。

DupHub API Key

安装/预览分身需要 DupHub API key（在 duphub.com 获取）。key 写入本机 .env，只存本地。

历史会话

来自网关台账（网关经手的轮）。点一条续接该会话；「新会话」从下一轮重新开始。
