本机网关

本机列表来自本机 aginx 网关（agent:// listAgents）；远程网关走同一协议（算力在他家，会话在对方侧，凭 sessionId 续接）。私有网关先在对方机器 aginx pair 生成配对码，在此输入绑定（🔒 后即主人设备，全放行）。聊天经网关路由到对应 CLI；移除会一并清掉该联系人的会话记录。

DupHub API Key

安装/预览分身需要 DupHub API key（在 duphub.com 获取）。key 写入本机 .env，只存本地。

历史会话

来自网关台账（网关经手的轮）。点一条续接该会话；「新会话」从下一轮重新开始。

扫码添加分身

没有摄像头或扫不了？选一张二维码截图，或关掉改用「＋ → 添加 agent」手输地址。

添加 agent

可带 /分身名 后缀直达该联系人；私有网关连接后按提示输配对码。

分享分身

对方在 aginx 里「＋ → 扫码添加分身」扫这个码即可。公开网关即扫即用；私有网关对方发访问申请、你在工具页「👥 访客管理」点同意（网关开 auto_approve 则自动通过）。
